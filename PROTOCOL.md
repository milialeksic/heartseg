# Experimental protocol

Written before any model training. Changes after seeing results must be logged in the changelog at the bottom.

## Task
Left atrium segmentation, MSD Task02 Heart (mono-modal cardiac MRI, 20 labelled volumes).

## Data split
- 4 cases held out as a final test set (touched once, at the end).
- 4-fold CV on the remaining 16 cases.
- Split generated by `medseg.splits.make_splits` with seed 42, saved to `configs/splits.json`, committed.
- Leakage checks: no case overlap (unit-tested); near-duplicate check on shape, spacing, intensity hash (TODO).

## Metrics (per case, then mean ± std and bootstrap 95% CI over cases)
- Dice
- HD95 (mm)
- Normalized surface Dice (NSD), tolerance TBD

## Models
1. MONAI UNet (baseline)
2. MONAI SegResNet
3. (optional) UNETR

## Training
- Loss: DiceCE. Optimizer: AdamW. Mixed precision.
- Fixed seeds; seed, config, git commit, and split fold logged to MLflow for every run.

## Preprocessing
- Orient to RAS, resample to configured spacing, z-score normalize on nonzero voxels.

## Error analysis
- Per-case CSV of all metrics.
- Inspect the 5 worst cases per model; record shared traits (size, spacing, artifacts).
